# Changelog

All notable changes to MoonPlan are documented here.

## 0.1.0 - 2026-09-30

- Initial public-ready release candidate.
- Added an explainable group scheduling and venue-selection core.
- Added dated time windows, hard attendance constraints, travel fairness and
  unknown-route handling.
- Added Pareto recommendations and automatic time-shift repair suggestions.
- Added tests, a runnable demo, CI, a versioned integration request contract,
  and a product-integration design note.
