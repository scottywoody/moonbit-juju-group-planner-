# MoonPlan 项目申报书

## 基本信息

- 项目名称：MoonPlan - 可解释的群体时间与地点约束优化库
- 参赛方向：新生态项目建设
- 主要语言：MoonBit
- 许可证：Apache-2.0

## 真实问题与目标

多人约时间、地点时，普通“共同空闲时间”算法会忽略关键成员、行程不公平、兴趣不匹配与路线信息缺失。MoonPlan 提供一个可复用的 MoonBit 核心库：输入匿名成员的可用时间窗、兴趣、候选地点通勤估算和规则，输出可解释的候选方案、拒绝理由及可行的改时建议。

目标用户包括活动组织者、课程项目组、社群管理员和需要排班/约见能力的应用开发者。项目的第一个真实应用来源是聚聚星组局场景，但核心不绑定任何产品、地图厂商或账号系统。

## 技术方案与创新点

1. **硬约束先行**：最低成团人数、关键成员、全员到场和通勤上限在排序前判定，避免高分方案牺牲不可替代的人。
2. **多目标、可解释**：同时衡量参加人数、兴趣匹配、平均通勤和通勤差；保留 Pareto 前沿，并输出“人最齐 / 最省心 / 最合兴趣”三类推荐。
3. **不确定性诚实建模**：路线未知与通勤超限、时间冲突明确区分，系统提示补充信息而不是虚构代价。
4. **可修复结果**：对未满足硬约束的时间候选，在 +/-30/60 分钟范围内搜索并返回实际可行的平移建议。

## 当前成果与开发计划

当前已完成纯 MoonBit 决策内核、15 项测试、可运行示例、JavaScript 构建验证和聚聚星接入数据契约。后续将补充命令行 JSON 输入输出、更多性质测试、基准场景与 Mooncakes 发布。

验收时提供公开仓库、README、示例、CI、测试记录、变更日志与发布版本。所有示例仅使用匿名 ID 和模拟通勤分钟数；不包含用户联系方式、精确住址或私有产品代码。

## 开源与维护承诺

项目采用 Apache-2.0 许可证。公开接口以稳定、无副作用、可复现为原则；每次规则调整附带测试和更新日志。欢迎社区贡献新的约束、优化策略、示例与不同平台适配器。
